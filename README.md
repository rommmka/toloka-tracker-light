# toloka-tracker-light

Публічна сторінка зі свіжими релізами toloka.to (фільми, серіали, мультфільми українською) у стилі toloka-tracker.
Без сервера і бази: лише статичні файли, тож підходить будь-який хостинг або GitHub Pages.

- **Сьогодні**: що приніс останній збір, роздача з найбільшою кількістю сідів, нове за категоріями.
- **Усі**: релізи за останні 45 днів, фільтри (категорія, жанр, якість, рейтинг TMDB), сортування.
- **Пошук**: за назвою серед зібраного, плюс посилання на пошук самої toloka.
- **Сторінка фільму**: опис, актори, трейлер, вибір якості. Дві кнопки для вибраної якості: сторінка роздачі
  на toloka і «Завантажити торент» з прямим посиланням на `.torrent`. Торент завантажиться лише тим, хто увійшов
  на toloka, решту toloka перекине на сторінку входу. Кнопки торента немає, якщо в експорті ще нема посилання.

## Звідки дані

toloka не показує сторінок без входу, тому сайт сам її не читає. Дані збирає приватний toloka-tracker на NAS
і щодня експортує їх сюди:

```
data/feed.json      картки для стрічок + час останнього збору
data/g/<id>.json    сторінка фільму: опис, актори, трейлер, усі роздачі
```

Експорт вручну (з теки toloka-tracker):

```sh
node scripts/export.mjs --out ../toloka-tracker-light
```

Після кожного збору NAS сам публікує зміни в `data/` одним комітом через GitHub API
(`SITE_GITHUB_TOKEN`, `SITE_GITHUB_REPO` у `config/.env` toloka-tracker; кнопка «Опублікувати сайт» на сторінці «Стан»).
Код сайту NAS не чіпає, його пушать вручну. Перед пушем робіть `git pull --rebase`, бо NAS щодня додає коміти з даними.

Постери беруться напряму з toloka.to / hurtom.com (віддаються без cookie), запасний — з TMDB.

## Локально

```sh
python3 -m http.server 8790
```

і відкрити http://localhost:8790.

## Структура

```
index.html, styles.css, manifest.webmanifest, icons/
js/main.js           маршрути #/, #/search, #/all, #/g/<id>
js/ui.js             DOM, формат, завантаження data/*.json, картки
js/views/            сторінки
data/                експорт з NAS
```
